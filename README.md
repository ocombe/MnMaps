# MnMaps

An illustrated fan map of Night Harbor from Monsters & Memories.

**Browse the map:** https://ocombe.github.io/MnMaps/

Drag to pan, scroll or pinch to zoom, and use the field guide to search for banks, inns, merchants, stables, and tradeskills. Select a place to center the map on it. You can add personal markers and notes; they stay in your browser. Use **Export notes** to keep a copy or move them to another device.

Community place names are based on Maggot’s Night Harbor wiki map. The atlas is an unofficial fan project and is not affiliated with the game’s creators.
